# Research, provenance, and external-project policy

RiVaL may study existing agent frameworks without assuming their implementations belong to this repository.

## Relevant references

- Cindy source: https://github.com/makecindy/cindy
- Cindy personal reference fork: https://github.com/AvaTar-ArTs/cindy-og
- Cindy plugins: https://github.com/makecindy/cindy-official-plugins
- Cindy plugin trademark notice: https://github.com/makecindy/cindy-official-plugins/blob/main/TRADEMARKS.md
- RiVaL repository: https://github.com/AvaTar-ArTs/RiVaL

Additional systems under consideration include Claude Code, Codex, Pi, Paperclip, and MCP-compatible services. These are references, not declarations of embedded dependencies.

## Provenance policy

For each adopted component or inspired feature, record:

- Source repository and version or commit.
- Whether implementation is original, modified, or directly reused.
- Relevant licenses, notices, and attribution requirements.
- Tests and evidence supporting behavior.
- Whether external services or protected marks are involved.

Maintain upstream attribution when reuse requires it. Do not imply affiliation with third parties.

## Local-development boundary

Local Cindy application state, sessions, credentials, databases, device identifiers, and companion memories are private runtime artifacts, not source material for automatic publishing. Audit and sanitize any material before considering inclusion.

## Naming

RiVaL is a working project name. Trademark clearance has **not** been established; public commercial branding requires separate review.
